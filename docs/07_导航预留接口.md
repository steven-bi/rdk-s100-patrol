# 导航预留接口

## 首版范围

首版检测系统不控制底盘，只接收四种标准事件：

| 事件 | 含义 | 检测侧行为 |
|---|---|---|
| 到点 | 导航确认到达一个候选点位 | 开始点位解析，AprilTag 优先、视觉指纹回退 |
| 暂停 | 底盘已经静止并允许采样 | 开始统一 5 秒停留窗口 |
| 继续 | 导航允许离开当前停留状态 | 停止本次点位窗口，保留已完成事件 |
| 离点 | 已离开当前点位 | 清除瞬态点位上下文，不能沿用上一点 |

所有点位首版使用相同固定停留时间 5 秒。车辆违停自身仍要求车辆进入有效禁停区持续 2 秒；导航 5 秒停留不能替代事件阈值。

检测侧正式 Python 接口为：

```python
bridge.arrive(point_id, point_name)  # 到点
bridge.pause()                       # 暂停并开始固定 5 秒窗口
bridge.resume()                      # 继续
bridge.leave()                       # 离点并清除瞬态上下文
```

导航适配器只把外部系统的可靠状态转换成这四个调用，不直接写检测内部状态或报警仓库。

## 安全边界

- 检测服务不发送速度、转向、制动或路径命令。
- 检测异常、MiniMax 超时、网页访问或录像压力不能阻塞底盘急停。
- 到点事件必须带单调递增或全局唯一事件 ID，重复消息应幂等。
- 暂停必须由导航确认底盘已静止；检测服务不凭光流自行宣称安全停车。
- 离点后清除点位上下文，避免下一位置沿用上一点的 ROI 或名称。
- 导航断开时，夜间人员和明火仍可按全画面规则运行；车辆/垃圾桶若无法可靠确定点位则跳过。

## MapPilot 边界

当前交付包没有复制、修改或嵌入 MapPilot，也没有假设其具体 API。后续应先单独验证：

1. 目标点能否稳定到达。
2. 停点误差是否满足 AprilTag/视觉指纹定位范围。
3. 暂停 5 秒期间是否真正静止。
4. 继续、离点、取消和急停状态是否可靠。
5. 仓库和依赖许可证是否允许目标部署方式。

完成导航验证后，只需编写一个适配器把导航状态转换成上述四种事件，不应修改四个检测规则或让导航系统直接写报警。
