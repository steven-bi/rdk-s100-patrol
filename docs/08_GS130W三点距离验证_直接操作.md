# GS130W 1米、3米、5米三点距离验证（直接操作）

> 这一步不是重新计算双目标定，而是用真实距离验证已经生成的双目标定尺度。候选标定保持 `valid:false`；只有三个固定距离槽全部严格通过，工具才另建一个 `valid:true` 文件。工具不会自动安装生产配置。

## 一、开始前只准备这些物品

1. 已打印的 A3 黑白随机纹理靶，平整贴在哑光硬板上。此步骤不用棋盘格，也不用 AprilTag。
2. 5 米以上卷尺；3 米、5 米最好两个人拉尺，卷尺不能明显下垂。
3. 固定 GS130W 的三脚架或牢固支架。
4. RDK S100、GS130W 摄像头和 Windows 电脑处于同一局域网。

全程固定 GS130W，只移动纹理靶。不要单独移动某个镜头，不要改变分辨率、左右目映射或 `ccw90` 旋转设置。

## 二、摆放和量距基准

1. 把 GS130W 固定并锁紧。三个距离点期间不要移动摄像头。
2. 把纹理靶竖直放置，纸面大致正对摄像头，不要明显俯仰或左右偏转。
3. 靶纸中心尽量与已确认的物理左镜头同高，并放在左右目画面中央。
4. 左右目都必须看见靶纸中心及其周围纹理，不能被人、卷尺或支架遮挡。
5. 每次都从同一个位置量距：

```text
物理左镜头前表面中心  →  靶纸中心标记
```

量的是两点间拉直的空间直线距离，不是地面距离，不是相机外壳或支架到靶纸的距离，也不是到纸张边缘的距离。

## 三、启动工具

1. 给 RDK S100 和 GS130W 通电。电脑连接到能访问 `192.168.66.65` 的局域网。
2. 直接双击：

```text
D:\RDK_S100_Patrol_Final\scripts\windows\启动GS130W三点测距验证助手.cmd
```

3. 黑色窗口出现密码提示时，输入板端 `sunrise` 用户密码并按 Enter。输入密码时屏幕不显示字符，这是正常现象；后续再次提示就再次输入。
4. 不要关闭黑色窗口。脚本会自动等待板端开机、上传当前工具、检查连续新帧、暂停融合巡检服务、建立 SSH 隧道并打开浏览器。
5. 浏览器应自动打开：

```text
http://127.0.0.1:8766/
```

网页必须同时显示“物理左目”和“物理右目”的实时新画面。若网页未打开，可手动打开上面的地址；若仍打不开，保留黑色窗口并截图，不要自己删除板端文件。

## 四、完成1米点

1. 把纹理靶移到约 1 米处并摆正、居中。
2. 从物理左镜头前表面中心量到靶纸中心，把卷尺实际读数记为毫米。例如实测 `1003 mm` 就输入 `1003`，不要强行输入 `1000`。
3. 1米槽只接受 `800–1200 mm`。确认左右目都能清楚看到靶纸，停止触碰摄像头、靶纸和卷尺。
4. 在网页的1米槽输入实测毫米数，点击一次“自动采集3帧”。
5. 保持完全不动，等待网页明确显示已经自动保存 `3/3` 个点击之后的新同步帧。
6. 网页会显示三帧中质量最好的一张“校正后物理左目”静态图。用鼠标只框靶纸内部、靠近靶纸中心且随机纹理丰富的区域：

   - 不包含纸张边缘、硬板、墙面或其他背景。
   - 不包含阴影、强反光、手、卷尺或运动物体。
   - 不要只框一个实心黑点，也不要把整张纸连同背景一起框入。
   - 1米可先框约 `100×75 px`，实际以完全位于纹理内部为准。

7. 点击一次“提交本轮共用 ROI”。这个框会自动用于同一轮的3帧，不能反复换小框碰运气。
8. 只有至少2帧通过，而且通过帧之间的估距差异也合格，1米槽才显示“已锁定”。

如果本轮失败，先按网页提示改善居中、光线、平整度或重新量距，然后点击“新建重试”。旧失败图和结果会保留，不会被算成另一个距离点。

## 五、完成3米点

1. 只移动纹理靶到约 3 米处，GS130W 仍保持不动。
2. 重新量“物理左镜头前表面中心到靶纸中心”的直线距离。
3. 3米槽接受 `2500–3500 mm`；输入实际毫米值。
4. 让靶纸正对、居中、照明均匀，停止触碰。
5. 点击一次“自动采集3帧”，等待 `3/3`。
6. 在质量最好的一帧上框一次纸内随机纹理区，建议先尝试约 `50×35 px`，不要带入背景。
7. 点击“提交本轮共用 ROI”，直到3米槽显示“已锁定”。

## 六、完成5米点

1. 只移动纹理靶到约 5 米处，重新量同一条直线距离。
2. 5米槽接受 `4300–5700 mm`；输入实际毫米值。
3. 5米处 A3 靶理论上在单目画面中可能只有约 `47×33 px`，因此必须尽量放在画面中央、纸面正对、照明充分且无反光。
4. 点击一次“自动采集3帧”，保持不动直到 `3/3`。
5. 在静态图中尽量框住靶纸内部较大的随机纹理区，建议约 `32–40×22–28 px`，仍不能带入纸边或背景。
6. 点击“提交本轮共用 ROI”。

如果页面提示 ROI 像素、有效深度像素或深度一致性不足，不得降低阈值，也不要连续换小框尝试。应改用随项目附带的 A1 四页拼接纹理靶或更大的非重复高纹理平面，重新做5米槽。

## 七、完成标志

三个槽全部通过后，网页会生成新文件并自动把完整审计包下载到电脑，然后安全结束板端验证进程。等待黑色窗口依次出现：

```text
VALIDATED_YAML_READY
LOCAL_AUDIT_OK
RDK_PATROL_ACTIVE
DISTANCE_VALIDATION_COMPLETE
```

四项都出现才算本次验证完整结束。CMD窗口会停留，便于截图；按任意键才关闭。

本地结果保存在唯一会话目录：

```text
D:\RDK_S100_Patrol_Final\calibration_data\GS130W_20260805\known_distance_validation\sessions\<本次session_id>\
```

其中包括候选原件副本、验证器副本、1/3/5米共9个同步帧、左右目图、组合图、校正图、ROI标注图、视差图、JSON审计链、SHA256清单、完整审计 ZIP 和新的 `stereo_gs130w_validated.yaml`。

`LOCAL_AUDIT_OK` 只表示审计包已经完整拉回且基础清单/哈希检查通过；它不等于已经批准安装。单独的审核安装器还会用归档并锁定版本的 `depth.py`、`calibration.py`、`gs130w.py` 对9帧重新计算视差、距离和全部质量指标。任何一项不一致都拒绝安装。

最终文件使用可重放事务生成。即使在生成文件前后意外断电，原候选仍保持字节不变；下次用原 `session_id` 加 `-Resume` 可核验并恢复。失败尝试和不完整审计尾部证据都保留，不会静默删除。

## 八、完成后先不要做的事

不要立即双击“审核并安装GS130W有效标定”。先把最终黑色窗口截图发给我；我会检查三个点的实测值、估计值、误差、有效像素、三帧一致性、候选哈希和 `valid:true`，确认无误后再给安装步骤。

不要手工覆盖：

```text
/var/lib/rdk-patrol/site-config/stereo_gs130w.yaml
```

## 九、中断或异常

- 需要暂停时，用网页的“安全暂停”，不要直接断电；窗口会给出保留的远端 session 信息。
- 只关闭浏览器不会自动结束板端验证器，黑色窗口必须保留。
- 若画面断流、候选 SHA256 不符、服务恢复失败或本地审计失败，工具会拒绝生成/安装生产标定；保留窗口并截图。
- 只有看到 `RDK_PATROL_ACTIVE` 后，才确认融合巡检服务已经恢复。
- 已保存数据、失败尝试和远端 session 不要自行删除。
