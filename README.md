# RDK S100 四功能融合巡检系统

这是面向 RDK S100、GS130W 双目相机的统一巡检版本。四类检测在**同一个主进程**内同时工作：共享一次相机取流、一次图像预处理和一次 HBM 推理，再把同一帧检测结果分发给车辆违停、夜间人员/人群、明火和垃圾桶复核引擎。它不是四个独立程序并行抢占相机和 BPU。

版本范围、验证结果、模型哈希和上线前现场项见 [交付清单](DELIVERY_MANIFEST.md)，全包文件校验值见 `SHA256SUMS.txt`。

## 首次使用结论

代码和部署包装齐全后，仍必须在实际设备上完成以下现场项，才可以进入生产巡检：

1. 确认 GS130W 组合画面中物理左右目，用同步棋盘图完成双目标定和至少三个已知距离点核验。
2. 打印并安装 `tag36h11` 标记，登记车辆禁停点和垃圾桶点；同时保留旧视觉指纹作为识别失败时的回退。
3. 在板端安全配置 MiniMax Key。
4. 完成 15 FPS、24 小时稳定性和 72 小时录像留存验收。

初始 `configs/stereo_gs130w.yaml` 的 `valid` 为 `false`，点位也标记为待登记。这是安全门，不是安装故障。

## 固定业务规则

| 功能 | 生效范围与确认规则 | 报警复位/冷却 |
|---|---|---|
| 车辆违停 | AprilTag 点位对应禁停区，车辆持续 2 秒 | 同点位 5 分钟冷却 |
| 垃圾桶已满 | 到点停留 5 秒，选一张质量最好的**整幅巡检画面**上传 MiniMax | 同点位 5 分钟冷却；网络失败持久化重试 |
| 夜间人员逗留 | 默认北京时间 22:00–06:00，全画面，1–2 人持续 5 秒 | 连续无人 30 秒重布防 |
| 夜间人群聚集 | 默认北京时间 22:00–06:00，全画面，至少 3 人持续 5 秒；只报人群聚集 | 连续无人 30 秒重布防 |
| 明火报警 | 全天全画面，只使用 `fire`，连续约 2 秒确认 | 持续事件每 10 分钟复报 |

明火距离是 GS130W 估算的“相机到明火区域”直线距离。测距失败不阻断明火报警，关键帧显示“距离：不可用”。

垃圾桶 MiniMax 提示词在代码中固定为：

> 图片中垃圾桶满了吗？如果图片中有多个垃圾桶或者一个垃圾桶有多个桶口，只要其中一个垃圾桶或者其中一个桶口满了就判断为已满，只输出一个词：已满 或 未满。

只严格接受“已满”或“未满”。

## 报警格式

- 车辆违停、垃圾桶已满：`关键帧图片 + 事件名称 + 北京时间 + 点位名称`
- 夜间人员逗留、夜间人群聚集、明火报警：`关键帧图片 + 事件名称 + 北京时间`

后三类记录完全省略 `point_name`，不会填空字符串冒充点位。网页和离线台账显示相同字段。

## 快速部署

默认板端地址为 `sunrise@192.168.66.65`。Windows 电脑可直接双击：

- `scripts\windows\部署到RDK.cmd`
- `scripts\windows\查看RDK状态.cmd`
- `scripts\windows\拉回报警台账.cmd`

也可参数化运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows\Deploy-RdkPatrol.ps1 `
  -BoardHost 192.168.66.65 -User sunrise -SshPort 22
```

部署默认位置：

- 程序：`/opt/rdk-patrol/current`
- 不可变历史版本：`/opt/rdk-patrol/releases`
- 运行数据：`/var/lib/rdk-patrol`
- 持久现场配置（业务参数、双目标定、点位）：`/var/lib/rdk-patrol/site-config`
- 密钥环境文件：`/etc/rdk-patrol.env`
- systemd 服务：`rdk-patrol.service`
- 局域网只读网页：`http://板端IP:8081/`（相机网页保留使用 8080）

详细顺序见 [RDK S100 部署与预检](docs/01_RDK_S100部署与预检.md)。

### GS130W 三点测距验证一键入口

完成棋盘双目标定并取得固定候选文件后，Windows 电脑直接双击：

```text
scripts\windows\启动GS130W三点测距验证助手.cmd
```

工具固定按 `1米 → 3米 → 5米` 运行。每个距离只需输入卷尺实测毫米值、点击一次自动采集3帧，并在最清晰帧中框一次纹理靶内部 ROI。候选文件不会被覆盖，三个距离全部严格通过后才会另建 `valid:true` 文件并拉回完整审计包；生产配置仍不会自动安装。完整操作见 [08：GS130W 1米、3米、5米三点距离验证](docs/08_GS130W三点距离验证_直接操作.md)。

## 重要数据策略

原始双目组合视频和标注主视图视频按 15 FPS 分段保存，默认保留 72 小时。实际码率不同会占用约 130–260 GB，建议使用至少 512 GB 的高耐久外置存储。

报警记录不随录像轮转而删除。拉回脚本只读导出自包含 HTML、JSONL、配置快照和诊断信息，**不会自动确认或删除报警**。只有人工核对拉回包并按现场制度确认后，才可另行清理。

## 导航边界

首版只预留“到点、暂停、继续、离点”接口，所有点位默认停留 5 秒。当前版本不包含导航控制，不复制或嵌入 MapPilot 代码；待导航系统单独完成授权、运动安全和停点精度验证后再接入。
